The Platform

CTRL+R is a browser-based robotics teleoperation platform that connects physical robots to operators over WebRTC, with fleet management, video streaming, navigation, and gamepad-based control. The system has two halves: a React webapp where operators control fleets, and a Rust agent that runs on each robot and bridges the platform to the local ROS2 stack.

My Role

Helped run day-to-day engineering operations on the CTRL+R agent and webapp. Owned product features from conception all the way through final deployment to clients and partners. Collaborated closely with an international team of engineers.

Key Contributions

Remote ROS2 Command Pipeline

Built a custom Rust ↔ ROS2 pipeline that lets users remotely create ROS2 topics and commands through the webapp and have them persist onto the robot from anywhere in the world, enabling robot customization without ever physically touching the machine. Managed the message schema interface between webapp and agent, and designed the webapp-driven waypoint navigation flow.

Cloud Simulation Environment

Built an AWS EC2 Isaac Sim server hosting six simulated robots across two back-to-back maps, each running its own ROS stack. The CTRL+R agent connects to it the same way it connects to physical robots, giving prospective users a hardware-free way to evaluate the platform. Also built a custom simulation environment inside Isaac Sim for a prospective customer, using a custom AprilTag API plus an EKF for localization.

Connectivity, Reliability & Safety

Diagnosed a TURN-server configuration issue and stood up the relay so users can connect behind NATs and firewalls. Built automatic reconnection and refresh into the system, plus the infrastructure for multiple reconnections per session.

Diagnosed and fixed silent WebRTC disconnects against AWS signaling, shipping a layered timeout and recovery design that bounds worst-case recovery to 10 minutes across all failure modes, including the AWS 2-hour hard connection limit, silent TCP death, and idle timeouts.

Deployment & Distribution

Dockerized the agent and packaged it into a one-line curl installer with automatic CPU architecture detection (correct image pulled per platform). Added dynamic ROS topic paths to a persistent on-robot config file so customizations survive reboots. Maintained and improved the CI/CD pipeline.

Telemetry Pipeline

Built a secondary, throttled data pipeline that exports robot data as MCAP files for real-time visualization, throttled deliberately to avoid impacting the control or video streams running over the primary WebRTC channel.

Cross-Platform Validation

Tested the agent on multiple physical robotic platforms across different ROS SDKs, Unitree, Slamtec, Bracket Bot, Viam Rover, surfacing and resolving platform-specific integration issues.

Impact

  • Helped secure the company's first major partnership.
