Repurposed 3D Printer

This project repurposes a 3D printer into an automated drawing and plotting machine. The printer’s tool head has been replaced with a custom made rotating pen holder that switches between CMYK colors to draw detailed images. This switching is done through the repurposing of the original printers filiment extruder motor.

The machine runs on custom made G-Code that is generated from an original input image. This image is loaded into a custom python script that then generates G-Code through a couple of image processing steps that are detailed below.

  1. Images are converted into a 600x600 matrix, with each cell containg the CMYK value of the corresponding pixel
  2. These cell values are then simplified and the values are converted from unique CMYK color values to a single digit (0-3) that represents the most promenent CMYK color in that cell. When white is the most prominent, the cell is left blank
  3. This new simplified matrix is then scaled down from 600x600 to 100x100. To do this cells are grouped into 6x6 bloacks these blocks are averaged, and the most prominent CMYK color digit is entered into the 100x100 matrix cell that represents this block.
  4. Now that there is a 100x100 matrix representation of the initial image with single digit numbers representing the color value of grouped together pixels, machine code (G-Code) is now made.
  5. The python script loops through each cell in the matrix, and creates G-Code that moves the modified tool head to the physical location that the matrix cell represents. The tool head then lowers and creates a small dot of the specified color.
  6. This process is done one color at a time and when the G-Code of a specific color has been generated, a command is then written to the extruder motor to rotate ninty degrees, allowing the next color to be used.
  7. This process is repeated for all four colors, with white space being skipped by the pens.
  8. This G-Code is then saved to a text file that is loaded into the printer and the physical drawing is created by the printer
