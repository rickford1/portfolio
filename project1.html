Repurposed 3D Printer

CMYK Plotter · Personal Project

Python G-code Image Processing

Overview

Converted an old 3D printer into an automated CMYK image plotter. The print head was replaced with a custom rotating pen holder that switches between four colors mid-print, driven by g-code generated from any input image by a custom Python script.

How It Works

  1. Image processing. The input image is downsampled to a 100×100 matrix, with each cell labeled by its dominant CMYK color.
  2. G-code generation. A Python script walks the matrix and emits g-code that moves the print head to each cell and dots the corresponding color.
  3. Color switching. The original extruder motor was repurposed to rotate the pen holder 90° between colors, letting the printer cycle through CMYK in a single run.
